# Practical 2 – Data Engineering

## Objective

This project demonstrates programmatic data generation, profiling, validation, and storage before ingestion into a relational database.

## Tools

- Python 3
- Faker
- Pandas
- Requests
- SQLite
- Git

## Files Generated

- customers.csv
- api_transactions.json
- config.txt
- ecommerce.db
- validation_report.csv
- quality_log.txt

## Workflow

1. Generate synthetic customer data.
2. Generate API transaction JSON.
3. Generate configuration file.
4. Profile customer dataset.
5. Validate data quality.
6. Store data into SQLite database.
7. Generate validation report and logs.

## Learning Outcomes

- Data Profiling
- Data Quality Validation
- Synthetic Data Generation
- SQLite Integration
- Logging
